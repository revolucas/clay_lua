# RGFW vendor

This directory vendors RGFW 1.8.1 from
[ColleagueRiley/RGFW](https://github.com/ColleagueRiley/RGFW), pinned at
commit `d96684e6877d3ef11c731b122b8949942ed071c9`.

`rgfw_wrapper.c` is Clay Lua's adapter around RGFW. The upstream `RGFW.h` is
kept unmodified; see `LICENSE` for its license.
